# jeysingh.com

Personal site for Jey Singh: books, portfolio, free learning, about and contact.

- Next.js (App Router), TypeScript, Tailwind 4. Fonts are self-hosted through Fontsource.
- Store links, prices and book facts live in `src/lib/site.ts`. Change them there.
- `/az104` redirects to `/books/az-104`. That short link is printed in the book, so keep it working.

```
npm install
npm run dev
```
